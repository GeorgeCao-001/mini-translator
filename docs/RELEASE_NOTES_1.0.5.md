# Mini Translator 1.0.5

## English

- **Edit and translate in the sidebar.** The source stays in place and grows as you type. Press Enter to translate, or Shift+Enter for a new paragraph. Paragraph breaks are kept in the result, when copying, and in history.
- **Return to your source.** Open a history item's source details to jump to the saved PDF selection or page, or to matching Markdown text. The sidebar also has a shortcut to plugin settings.
- **Browse recent popup results.** Use the arrow controls to review up to five previous translations and return to the current result.
- **DeepL and Keychain.** Added the official DeepL text API for users with their own key. LLM, Azure/Bing, and CNKI credentials can opt in to Obsidian Keychain; DeepL always uses it.
- **Compatibility.** Simplified the advanced typography CSS while preserving underline and strike-through. No new runtime dependencies. Requires Obsidian 1.13.7 or newer on desktop.

## 简体中文

- **在侧边栏就地编辑原文。** 输入框随内容伸缩。回车翻译，Shift+Enter 另起一段；分段保留在译文、复制内容和历史中。
- **从历史回到原文。** 展开来源详情，可跳到 PDF 选区或页码，也可定位到匹配的 Markdown 原文。侧边栏新增设置快捷入口。
- **快速翻看悬浮窗历史。** 用箭头浏览最近五条译文，随时返回当前结果。
- **新增 DeepL 与钥匙串。** DeepL 使用用户自己的官方 API Key；大模型、Azure/Bing、CNKI 可选用 Obsidian 钥匙串。
- **兼容性修复。** 简化高级排版的 CSS，保留下划线和删除线。不新增运行时依赖，最低支持桌面版 Obsidian 1.13.7。

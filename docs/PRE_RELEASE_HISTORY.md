# 发布前内部迭代记录

> 这些编号是公开发布前的内部开发构建标签，不是 Obsidian 社区插件的公开版本。
> 首个公开版本从 `1.0.0` 开始；后续公开变更请记录在根目录 `CHANGELOG.md`。

## 内部构建记录

### v3.1.0 (internal)

加入“原文语言 → 译文语言”选择（原文可自动识别）、多语种排版、
Bing 与 CNKI 翻译源；缓存、历史、全文翻译和 LLM 提示词均隔离语言对。
非中英文语言明确标注为仅经 AI/接口自动化测试、未经母语者审校。

### v3.0.53 (internal)

章节标题投影增加长度/句末过滤，避免表格数值或短正文被误放大为标题。

### v3.0.52 (internal)

识别省略冒号的 Figure 图注，清理信息图/流程图短字号标签，避免图内
文本与正文重复；全文 Markdown 将章节标题投影为 Obsidian 标题。

### v3.0.51 (internal)

Markdown 原页附件只保留检测到图片或表格的页面，不再默认额外保留首页；
HTML 对照模式仍保留全部原页，含图/表页检测与段落缩进不变。

### v3.0.50 (internal)

脚注先从每页正文流中整体剥离，双栏正文完整读完后才进入独立脚注流；
小字号、栏底连续区、字号突变、注号/作者信息等证据联合判定，避免脚注横插两栏。

### v3.0.49 (internal)

全文翻译按 PDF 逻辑内容流与版面栏沟重建真实阅读顺序，单双栏逐页判定，
跨栏断词/续段安全衔接，旋转页边文字不再插入正文；停用不可靠的 Figure
自动裁片，改为折叠保留含图/表完整原页，复合图不再碎裂、重复或截断。

### v3.0.48 (internal)

全文 Markdown 使用独立可读版式并修复会污染整篇笔记的孤立数学定界符；
自动识别/裁出 PDF 位图区域；HTML 改为原页与自然流式译文分栏，彻底移除
原位白块覆盖与“显示原文”双层重叠，保留段落到原页位置的交互定位。

### v3.0.47 (internal)

修复全文翻译错误被吞掉：网络/鉴权/API/写入错误不再伪装成“批次解析失败”；
单文件失败会保留红色错误进度窗并弹出长通知，全块失败按任务失败处理且错误不进缓存。

### v3.0.46 (internal)

宽度预设只约束弹窗自动打开时的宽度；用户从右下角手动缩放后可继续放宽，
仅受当前视口边界限制，记住并恢复的手动宽度也不再被预设截断。

### v3.0.45 (internal)

把上一版“紧凑”的 420px 宽度作为新的“标准”，其余宽度预设再整体下移一档；
新紧凑为 320px，自适应基础上限同步降为 420px。

### v3.0.44 (internal)

翻译框尺寸加入自定义宽高与“记住上次大小”；各预设最大宽度整体下调一档，
恢复的尺寸仍会按当前预设、视口和原文上下方可用空间安全裁剪。

### v3.0.43 (internal)

侧边栏全文翻译入口改为轻量工具条；划词翻译框支持拖动右下角自由缩放，
设置中可选择默认最大尺寸，同时继续遵守屏幕边界与“不遮挡原文”的定位规则。

### v3.0.42 (internal)

侧边栏“全文翻译”补齐当前 PDF 与文件选择（支持多选）两个入口。

### v3.0.41 (internal)

修复大模型配置页刷新时重复追加整套编辑界面；查询/添加/删除/切换模型后
统一从根容器重绘，并给模型查询加互斥与“查询中”状态，避免重复请求。

### v3.0.40 (internal)

翻译框加入大屏响应式倍率；2K/4K 视口会同步放宽尺寸上限并轻微放大文字，
普通窗口保持原尺寸，极大屏幕也设有倍率上限，避免弹窗反过来铺满屏幕。

### v3.0.39 (internal)

修复 Markdown/阅读视图中选区坐标偶发漂移；弹窗锚定实际文字选区，
译文回填时锁定初始上/下方位并在该侧滚动，不再随内容变高而“乱飞”。

### v3.0.38 (internal)

划词翻译框按原文+译文字数平滑放大（最大 760px / 72vh），侧边栏新增全文翻译按钮；
发送翻译源与弹窗展示共用同一份英文排版结果，彻底消除“看到的原文”和“实际发送原文”不一致。

### v3.0.37 (internal)

公式占位符改用各翻译源更稳定的 ASCII token，并保留公式前后空格；

### v3.0.36 (internal)

补齐所有句子/段落及全文批次入口的统一源文本重排，并移除 PDF 常见软连字符。

### v3.0.35 (internal)

所有翻译源统一先重排 PDF/复制文本的硬换行与断词，再发送翻译请求，避免免费源逐行误译。

### v3.0.34 (internal)

### v3.0.33 (internal)

### v3.0.31 (internal)
